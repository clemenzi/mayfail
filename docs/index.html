tcatch()

A tiny, dependency-free error handling helper for TypeScript.

tcatch runs a function and returns its value alongside a possible error. Instead of wrapping each call in try/catch, you can handle both outcomes from one predictable tuple. It works with synchronous functions, promises, and async functions without changing their execution model.

Installation

npm install tcatch

Usage

import { tcatch } from 'tcatch'

const [config, error] = tcatch(() => JSON.parse(input))

if (error) {
  console.error(error.message)
}

When the callback succeeds, the first item contains the value and the second is null. When it throws, the value is null and the second item is an Error.

Async usage

const [user, error] = await tcatch(() =>
  fetch('/api/me').then((response) => response.json()),
)

You can use it with an async callback as well:

async function getUser(id: string) {
  const [user, error] = await tcatch(async () => {
    const response = await fetch(`/api/users/${id}`)

    if (!response.ok) {
      throw new Error('Unable to load user')
    }

    return response.json()
  })

  if (error) return null
  return user
}

API

tcatch(callback)

Executes callback and catches thrown errors or rejected promises. Non-Error values are converted to Error instances. 

function tcatch<T>(callback: () => T): Result<T>
function tcatch<T>(callback: () => Promise<T>): Promise<Result<T>>

type Result<T> = [T, null] | [null, Error]

Synchronous callbacks

Return a Result<T> immediately.

Async callbacks

Return a Promise<Result<T>>. Await it before reading the tuple.

Aliases

tc and tryCatch are aliases for tcatch.

import { tc, tryCatch } from 'tcatch'
